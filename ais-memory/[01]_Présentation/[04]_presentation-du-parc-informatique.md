# Présentation du parc informatique

Notre parc informatique est constitué de :

- 250 Caméras AXIS / BOSCH :
    - 200 Caméras Analogique
    - 50 Caméras IP
- 6 Hosts Windows Server 22 - Hyper-V
    - MGT-1 : Management N°1
    - MGT-2 : Management N°2
    - REC-1 : Record N°1
    - REC-2 : Record N°2
    - REC-3 : Recorde N°3
    - KIMERA
- 1 VM Rocky Linux - Squid Proxy
- 1 VM Rocky Linux - Zabbix Server
- 1 VM Contrôle d’Accès (CA)
- 1 VM Contrôle d’Intrusion (CI)
- 1 VM Contrôle des SAS Fischer (SAS)
- 1 VM KeyCabinet pour la gestion des armoires à clefs
- 1 VM Windows Server 22 - Veeam Backup
- 1 VM Windows Server 22 - Milestone XProtect - VMS

Notre réseau est constitué de :

- 4 VLAN’s :
    - 1 VLAN pour le Contrôle d’Accès (CA)
    - 1 VLAN pour le Contrôle d’Intrusion (CI)
    - 1 VLAN pour les Caméras (CCTV)
    - 1 VLAN pour les Armoires à Clefs (KC)
